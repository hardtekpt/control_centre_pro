# NirCmd Binary

This directory should contain `nircmd.exe`, required for setting the primary display.

## Setup

1. Download `nircmd.exe` from: https://www.nirsoft.net/utils/nircmd.html
2. Place the `nircmd.exe` file in this directory (`resources/nircmd/`)
3. The executable will be bundled with the app during `npm run package`
